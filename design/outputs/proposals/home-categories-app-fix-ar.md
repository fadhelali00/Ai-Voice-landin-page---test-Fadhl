# إصلاح عرض أقسام الفئات في الرئيسية (تطبيق العميل)

**التاريخ:** 2026-10-21 · **المسؤول:** عبيد (Flutter) · **التصنيف:** MVP Now (معتمد ضمن استثناء "المبيعات وتجربة العميل")

## المشكلة (ما شوهد)
- الرئيسية تُبنى الآن من Home Page Builder. الإعداد `Settings > System > Home Page Layout = New Home Builder`.
- **الموقع jarna.co يعرضها صحيحاً.** أكد فضل ذلك، فكل قسم فئات يعرض مربعاته كاملة من `content.categories`.
- **التطبيق يعرض أقسام المنتجات صحيحاً**، مثل "العروض" و"مختارات الطازج". **لكن كل قسم من نوع `categories` يُرسم بالكتلة القديمة:**
  - أول 3 أقسام رئيسية فقط.
  - ثم زر "عرض الكل".
  - مع تجاهل المربعات المحددة في القسم، ونمطه (`style`)، وإعداداته (`rows_layout` و`grid_columns`).
- جربنا النمطين `default` و`card`، والنتيجة نفسها في التطبيق.

## البيانات المتاحة (لا تحتاج تعديل Backend)
`GET /api/home-layout?platform=app&latitude=..&longitude=..&per_page=20` يرجع 13 قسماً. وقسم الفئات بهذا الشكل:
```json
{ "type": "categories", "title": "الطازج", "style": "card",
  "config": { "source": "custom", "rows_layout": "grid", "grid_columns": "4", "background_type": "none" },
  "content": { "categories": [ { "id": 75, "title": "الفواكه", "slug": "alfoakh", "image": "...", "product_count": 89 }, "... 11 مربعاً" ] } }
```

## المطلوب
1. في رسم قسم `type == "categories"`:
   - اعرض **`section.title`** عنواناً للقسم.
   - اعرض **كل** عناصر `section.content.categories` بالترتيب الوارد.
   - استخدم شبكة بعدد أعمدة `config.grid_columns`، وهو 4 حالياً.
   - **بلا حد أقصى وبلا زر "عرض الكل"**، مثل الموقع.
2. الضغط على مربع يفتح صفحة الفئة بالـ `slug` نفسه (العمود الجانبي مع "الكل")، كما يحدث الآن.
3. لا تغيير في البطاقة أو الألوان أو زر السلة.
4. التزم بترتيب الأقسام كما يرجع من الـ API (`sort_order`).
5. انتبه للترقيم: الـ API يرجع افتراضياً 5 أقسام (`per_page=5`)، فاجلب الصفحات التالية أو اطلب `per_page=20`.

## القبول
- **في الرئيسية بالترتيب:** العروض ← الطازج (11 مربعاً) ← مختارات الطازج ← المقاضي (13) ← مختارات المقاضي ← المشروبات (8) ← مختاراتها ← السناكات والحلى (8) ← مختاراتها ← الجمال (7) ← مختاراته ← المنزل (2) ← الأطفال (2).
- لا يظهر "عرض الكل" ولا "أفضل العلامات التجارية".
- مقارنة بصرية مع jarna.co بمقاس الجوال.

## مرجع
- كود الموقع (Next.js) يرسم القسم في المكوّن الذي يستخدم `getSectionCategories(section.content)` و`config.rows_layout === "grid"`.
- ملف التخطيط: `catalog/home-layout/layout_app_2026-10-21.json`.
