# حالة مهام السيرفر والبنية التحتية

**التاريخ:** 2026-10-30.

**المصدر:** فحص مباشر للوحة الإدارة (Cron Monitor، وتحديثات النظام، والإعدادات)، وللنطاقات وشهادات HTTPS. قراءة فقط، بلا أي تعديل.

**المهام المقصودة:** مهام البنية في خارطة الطريق على Notion (لقطة 10-22). كلها كانت بلا مسؤول.

## الخلاصة
**لم تُنجز بالكامل.** المنجز: النطاقات والشهادات وأيقونات PWA والمهام المجدولة. **وبقيت 3 مشاكل حرجة قبل الإطلاق:**
1. **الإشعارات لا تعمل**، لأن عامل الطابور (Queue Worker) غير مُعَد.
2. **وضع اختبار OTP مفعّل.**
3. **البريد الإلكتروني (SMTP) غير مُعَد.**

## التفاصيل
| المهمة (Notion) | الحالة الفعلية | الدليل |
|---|---|---|
| إصلاح صلاحيات أيقونات PWA وخطأ 403 | ✅ **منجزة** | أيقونات 192 و512 ترجع 200، و`jarna.co/manifest.json` يعمل. أما 403 على المجلد نفسه فطبيعي، لأنه يمنع عرض محتوى المجلد |
| تهيئة Nginx للنطاقات | ✅ **تعمل** | `jarna.co` و`admin` و`seller` و`api` كلها تعمل على HTTPS، و`www` يحوّل إلى `jarna.co` |
| شهادات HTTPS | ✅ صالحة حتى **29 نوفمبر 2026** | ⚠️ يُتأكد أن التجديد التلقائي مفعّل (Let's Encrypt كل 90 يوماً) |
| جدولة Laravel (`schedule:run`) | ⚠️ **تعمل فعلياً** | المهام تُنفَّذ: فحص الطلبات العالقة كل 5 دقائق (آخر تشغيل قبل 4 دقائق)، والرفع الجماعي كل دقيقة، ونقاط الولاء كل ساعة. لكن الشاشة تقول "Not detected"، فيُضبط مؤشر الكشف |
| **عامل الطابور (`queue:work`)** | ❌ **غير مُعَد، حرج** | صفحة تحديثات النظام: *"Notifications are currently not functioning because the required cron job has not been configured"*. **الإشعارات لا تُرسل، وتحديثات النظام معطلة.** الحل سطر Cron واحد تعطيه الصفحة نفسها |
| إعداد Firebase وربط التطبيقات | ⚠️ **جزئي** | المشروع `delivery-507308` مربوط لتسجيل الدخول. **لم يُتحقق** من ملف حساب الخدمة للإشعارات (حقل ملف لا يظهر محتواه). ومفتاح VAPID لإشعارات الويب فارغ، ومعرّف التحليلات قيمة مؤقتة `G-0000000000` |
| **وضع اختبار OTP** | ❌ **مفعّل، حرج أمنياً** | `otpTestMode = ON`: الدخول برمز اختبار ثابت. **يجب إيقافه قبل الإطلاق** |
| **إرسال رسائل SMS** | ❌ **غير حقيقي** | رابط SMS المخصص قيمة مؤقتة (`whatsloop.internal/unused-…`)، ومفتاح Authentica فارغ. يُحدَّد مزوّد رسائل OTP الحقيقي (Firebase أو مزوّد سعودي) |
| **البريد الإلكتروني (SMTP)** | ❌ **فارغ** | الخادم والمنفذ والبريد كلها فارغة، فلا تُرسل رسائل البريد (الفواتير، واستعادة الحساب) |
| تخزين الملفات | ⚠️ **على السيرفر نفسه** | لا تخزين سحابي ولا نسخ احتياطي ظاهر. يُوصى بنسخ احتياطي يومي لقاعدة البيانات والملفات |
| ضبط APP_URL وترخيص النظام | ❓ **لم يُتحقق** | لا يظهر تنبيه ترخيص في اللوحة، والإصدار v1.0.0. يُؤكَّد مع محمد |
