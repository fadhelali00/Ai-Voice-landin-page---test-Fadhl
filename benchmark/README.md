# قياس الجاهزية والمقارنة التنافسية

يديره وكيل `readiness-benchmark` (التعريف والمنهج الكامل في `.claude/agents/readiness-benchmark.md`).

- `scorecard-<التاريخ>.md`: بطاقة كل قياس (الدرجة، المحاور، المربعات، الفجوات، التوصيات).
- `history.csv`: صف لكل قياس لمتابعة التقدم.
- `tasks/`: مواصفات مهام جاهزة لعبيد ومحمد والتشغيل، تُرفع بعد موافقة فضل.

**الأهداف (فضل، 2026-10-22):**
- دارك ستور واحد في الرغامة، يغطي 8–10 كم².
- التوصيل خلال 15 دقيقة أو أقل.
- التوفر 99–100%.
- 200 طلب يومياً في الشهر الأول.

**الأوزان:**

| المحور | الوزن |
|---|---|
| الكتالوج | 30 |
| التوفر | 20 |
| السعر | 10 |
| الواجهة وتجربة الاستخدام | 20 |
| التشغيل | 20 |

**مستويات الجاهزية:**

| الدرجة | المستوى |

| أقل من 50 | غير جاهز |
| 50–69 | تجريبي داخلي |
